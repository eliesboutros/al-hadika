# 🌿 Al-Hadika Pest Control & Garden Services

Website for **Al-Hadika**, a pest control and garden services company based in Batroun, Lebanon.  
Built with Ruby on Rails.

**Tagline:** *We eliminate what bugs you.*

---

# About

This project is the official website for Al-Hadika.  
It provides information about services, allows customers to contact the business online, and integrates tools like WhatsApp and Google Maps for easier communication.

Main goals of the website:

- Present the company’s services clearly
- Allow customers to send messages through a contact form
- Show business hours and live open/closed status
- Make it easy to contact the business through WhatsApp
- Display the company location on Google Maps

---

# Features

### Core Features

- Responsive layout that works on mobile, tablet, and desktop
- Contact form that sends emails directly to the business
- Automatic business status indicator (open / closed)
- Service details shown in interactive modals
- Google Maps integration
- WhatsApp quick contact links

# Tech Stack

- **Ruby:** 3.3+
- **Rails:** 8+
- **Frontend:** Tailwind CSS, ERB, Vanilla JavaScript
- **Database:** PostgreSQL (SQLite in development)
- **Email:** ActionMailer with SMTP
- **Deployment:** Compatible with Render, VPS, or other Rails hosts
